# PathFEA 3D：通用打印件静力分析

双击 `start3d.cmd` 启动。保留原二维版 `start.cmd`。依赖安装：`python -m pip install -r requirements.txt`。

已增加 **tetra 贴体四面体网格**、分块装配、AMG 迭代求解及走线空间索引。界面“几何 / 走线”选择 voxel/tetra，“材料”页选择 auto/direct/amg。下面关于体素网格的数量限制只针对 voxel；贴体模式最多 60 万单元，另受 Agent 的超时/内存阈值约束。新增参数及精度边界见 [Agent 接口](AGENT_API.md)。

## 输入与工作流程

1. 输入闭合 STL，单位必须为 mm；留空可使用解析验证用长方体。模型不限于连接件。此版本不生成 CAD 几何，不直接读取 3MF。
2. 设置体素网格间距。先预览，确认薄壁、孔洞和连接处保留；每个体素细分为六个线性四面体。STL 使用体素中心内外判定，边界呈阶梯状。最多 16000 个实体体素 / 96000 四面体，包围盒最多 150000 个采样点。
3. 设置材料九参数：沿线 E1、层内横向 E2、层间 E3、G12/G23/G13、nu12/nu23/nu13。默认数据仅用于演示，不能当作具体耗材性能。
4. 没有 G-code 时可设置统一走线角和层法线 X/Y/Z。局部零度参考分别为：法线 X 时沿 Y，法线 Y 时沿 Z，法线 Z 时沿 X。输入 G-code 时使用世界 Z 为层法线，各单元按最近层、该层最近挤出线段分配方向。
5. STL 和 G-code 保留原坐标。用路径 XYZ 平移对齐，预览黑色路径并检查路径距离场。不会自动居中；旋转需事先在建模/切片环节统一。去除裙边、擦料塔、支撑及其他零件路径后再导入。路径距离只是覆盖诊断，不等于填充率。
6. 固定区与加载区可选六个包围盒极值面，或输入空间盒 `xmin,ymin,zmin,xmax,ymax,zmax`。盒内的表面三角形中心被选中。预览固定区蓝色、加载区橙色，避免选到背面。固定区域三向位移为零，合力按加载表面面积一致分配。固定与加载区域共享节点会被拒绝。
7. 运行后查看位移、等效应力、沿线/横向/层间正应力、路径距离、走线角。Z 比例滑块通过移除上部单元显示内部，切面随网格呈阶梯状。放大变形会标注倍率。
8. 导出完整结果 JSON 和 VTK；VTK 可在 ParaView 中进一步切片。保存/载入工况用于复用不同零件的参数。修改输入不会自动重新求解，云图和结果导出始终对应上一次成功求解。

## 批量运行

复制 `example_case.json` 修改参数，然后执行：

```powershell
python run3d.py example_case.json --output output/demo
```

CLI 已升级为 Agent 接口，默认额外求解一档细化网格，并生成无界面云图及 HTML 报告。`output/demo.json` 为结果清单，NPZ、VTK、PNG、报告放入清单中指向的唯一运行目录。**CLI 的输入相对路径以工况 JSON 所在目录解析**；桌面界面仍以工作目录解析。可以为不同尺寸、网格间距、走线角、载荷保存工况后逐个运行。协议、错误码、超时、取消和资源阈值详见 [Agent 接口说明](AGENT_API.md)。

## 模型边界与数值精度

- 三维小变形、线弹性、实心等效体；不重建每条挤出线的截面、填充空隙和接触界面。低填充率件必须提供经过标定的等效材料，否则会高估整体刚度。
- 不包括螺栓预紧、装配接触、摩擦、塑性、疲劳、屈曲、裂纹和层间脱粘。多个不连通实体会被拒绝；不能将装配 STL 当作自动粘结的结构分析。
- 此版本一次一个固定区域和一个合力区域。固定是三向全约束，尚不支持滑移约束或独立多个载荷区。
- G-code 解析器支持常见单工具平面 G0/G1、G90/G91、M82/M83、G92；拒绝圆弧和非平面挤出。宏、工作坐标偏移、多工具状态不受支持。
- 最近层方向映射是等效近似；单元跨越多个打印层时，不进行分层积分或层合材料均匀化。网格大于实际层高时，交替填充方向可能欠采样。此时应使用标定的均匀等效参数，不能认为多层 G-code 已被精确解析。
- 线性四面体在粗网格弯曲问题中偏硬，接近不可压缩时也存在锁定。必须比较至少两档网格，检查位移及目标区域应力收敛；孔边和薄壁需要更细网格。测试悬臂梁中 1 mm 网格相对梁理论位移误差约 21%，0.5 mm 网格降到 12% 以下，这不是任意零件的精度保证。
- 固定边缘、尖角的应力峰值可能随网格增加。von Mises 仅作显示量，不用于各向异性破坏判定；工具不输出安全系数或断裂载荷。

## 验证

`python -m unittest -v test_solver.py test_solid.py` 验证二维回归、三维均匀拉伸解析解、各向同性旋转不变性、90° 各向异性刚度、反力和力矩平衡、弯曲网格收敛、路径层映射、STL 导入、结果导出及错误约束。`python smoke_ui3d.py` 检查界面求解与绘图。

三维正交各向异性柔度参考：[Sandia LAMÉ 三维正交各向异性模型](https://www.sandia.gov/files/sierra/SM_LAME_5_26/main/models/elastic_3D_ortho.html)。本工具独立使用 NumPy/SciPy 实现，局部工程应变顺序为 xx,yy,zz,xy,yz,xz；刚度以 Tᵀ D T 映射。
