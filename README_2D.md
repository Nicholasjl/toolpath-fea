# PathFEA：考虑打印走线的有限元工具

已有通用三维版：双击 `start3d.cmd`，支持闭合 STL、空间选区、三维各向异性及多层路径映射。详见 [三维使用说明](README_3D.md)。下文为原二维版。

双击 `start.cmd`，或在此目录运行 `python app.py`。依赖安装：`python -m pip install -r requirements.txt`。

这是可运行的二维平面应力静力分析原型。默认几何为实心矩形薄板，左侧完全固定，右侧施加均布合力。单位统一为 mm、N、MPa。默认材料参数只是演示值，不代表特定 PLA 或打印工艺的标定数据。

## 使用

1. 设置板长、高度、厚度、网格，以及沿线 E1、横线 E2、面内剪切 G12 和泊松比 nu12。
2. 指定统一走线角度，或导入文本 G-code 后选择一个 Z 层。切片器需关闭圆弧拟合。
3. 点击运行，切换位移、等效应力、沿线/横线应力、方向、路径覆盖距离图。工具栏可缩放或保存图片。
4. “对比”单独求解 0°、45°、90° 的均匀材料方向，报告最大位移；对比时不使用导入路径，原云图保留。
5. 导出 JSON 保存完整节点、单元、位移、全局和局部应力、参数及映射路径；CSV 保存逐单元结果。

## 路径映射与适用范围

G-code 提取具有正挤出增量的 G0/G1 直线段；支持 G90/G91、M82/M83、G92。拒绝 G20 英寸、G2/G3 圆弧和非平面挤出。只接收解压后的 `.gcode`，不接收 `.3mf` 或二进制 G-code。未实现机床宏、坐标系偏移及多工具独立挤出状态，需先导出普通单工具路径。

所选层 XY 包围盒的左下角平移至模型原点，不缩放路径。请仅使用目标零件路径，先移除擦料塔、裙边等；板长和板高需匹配实际分析区域。每个三角单元按其中心到最近线段的精确距离选择材料方向；覆盖距离图用于检查远离路径的区域。最近路径映射不重建孔隙或零件外形，不把该层变成真实填充网格。

当前不支持任意 STL、三维体单元、层间开裂、接触、塑性、热残余应力、非平面打印及面外弯曲；厚度方向仅作为平面应力积分厚度。稀疏填充不能仅凭方向得到可靠等效刚度。固定角点的应力峰值受边界奇异性和网格影响。von Mises 仅作为应力显示量，不是各向异性失效判据。本版本不报告安全系数。

## 数值实现和验证

常应变三角形 (CST)，每节点两平移自由度，SciPy 稀疏直接求解。局部柔度矩阵使用 nu21 = nu12 E2 / E1；工程应变变换 T 将局部刚度映射为 Tᵀ D T，材料矩阵须正定。右边载荷用线性边界形函数的一致节点力分配。

运行 `python -m unittest -v test_solver.py`，覆盖各向同性旋转不变性、均匀拉伸解析解、90° 方向刚度比、反力平衡、悬臂梁网格收敛、最近线段映射、G-code 模态与错误材料。

本构参考：[Jeremy Bleyer / FEniCSx 正交各向异性平面应力示例](https://bleyerj.github.io/comet-fenicsx/tours/linear_problems/isotropic_orthotropic_elasticity/isotropic_orthotropic_elasticity.html)。本项目独立使用 NumPy/SciPy 实现，不依赖 FEniCS。
