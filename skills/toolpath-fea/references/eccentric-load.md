# 偏置载荷与校核

`force: [Fx,Fy,Fz]` 是合力 N，`load_point: [x,y,z]` 是世界坐标施力点 mm，目前通过 CLI 配置使用。不要把 G-code 对齐用的 `offset` 当作力臂。

例如板位于 XY 平面、厚度范围 Z=0..5 mm，重物向下是 -Y，挂点超出正面 10 mm：

```json
{
  "force": [0, -9.80665, 0],
  "load_point": [118, 118, 15]
}
```

这段是配置片段，仍需模型、材料及固定/加载选区。相对正面参考点 q=(118,118,5)，M=(p-q)×F=(98.0665,0,0) N·mm。若参考点在厚度中面，力臂是 12.5 mm，不能仍报告 10 mm。偏置方向与载荷平行时弯矩为零，不能一律用标量 F×10。

`surface_load` 在选定表面按节点分担面积分配合力，并补充等效力偶。以面积权重 w、加权中心 c、r=x-c 定义 J=Σw[(r·r)I-rrᵀ]，解 Jω=(p-c)×F，节点载荷 f=wF+w(ω×r)。这保持合力与作用点力矩，不是刚性连接或单边接触；可能出现正负表面牵引。

核对 Σf=F、Σ[(x-q)×f]=(p-q)×F，并把固定节点反力加入总力与总矩检查。已有 `test_eccentric.py` 验证合力合矩、坐标平移不变性、反力平衡与线性缩放。不要再额外加一次相同的弯矩。

做力臂对比时固定载荷幅值、加载面、网格、材料和约束，只改变 load_point。所谓“0 mm”需写明在正面，仍可能相对板厚中面偏心。若改变拉力方向，另存工况，不沿用旧对比结论。
