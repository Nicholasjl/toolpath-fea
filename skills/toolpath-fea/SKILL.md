# 打印走线有限元分析

使用已有求解器完成可复现的数值筛查，保存工况、输入哈希、求解结果及限制。此 skill 是本机流程入口，求解器不随 skill 打包。

## 本地入口

求解器位于包含此 skill 的仓库根目录（从当前文件向上两级目录），也可使用用户指定的克隆路径。本机历史路径为 `D:/3d/toolpath_fea`；安装 skill 到全局目录后，需定位实际克隆目录。先确认路径存在，阅读项目 `AGENT_API.md` 和当前 `case.schema.json`；以当前实现为准。若迁移机器，定位实际项目或向用户索取项目位置，不凭空声称已安装求解器。

- Agent 使用 `run3d.py`；桌面入口 `start3d.cmd`。
- 配置由 `agent_worker.py` 校验；核心为 `solid.py`、`numerics.py`、`meshing.py`。
- 修改求解器时运行相关回归测试；单纯改变工况时检查新结果即可。
- 复用洞洞板基线时读 [references/g5-baseline.md](references/g5-baseline.md)。其他零件不要继承此例的材料、底部夹紧或加载孔位。

## 建立工况

1. 确认几何版本、单位、打印姿态、材料、约束位置、拉力方向和作用点。保留原始模型与发布快照，分析文件放入独立目录。未指定且可用于初步比较的参数可以明确假设；不要把假设当作实际安装条件。
2. 单位为 mm、N、MPa。质量转力用 `F=m*9.80665`，1 kg 是 9.80665 N。偏置须说明从正面、中面还是其他参考点量起；参见 [references/eccentric-load.md](references/eccentric-load.md)。
3. 用 `fixed`、`loaded` 面名称或包围盒选区。盒选按表面三角形中心判断，三角形可能伸出盒外。核对报告中的面积、三角形数和实际范围；固定与加载不能共享节点。默认是全位移固定，不等于螺钉或接触支承。
4. STL 默认 `mesh_mode: tetra`，TetGen 默认 `pq1.4Q`，质量细化与边界拆分均启用；不要使用缺少小写 q 的 `pYQ` 作为默认。`pitch=2mm` 是起点、对应目标体积，不是精度保证。检查 MESH_VOLUME_SIZE 的实际单元体积和加权p95；两档网格的加权p95须实际下降，不能只比较表面节点数或位移。允许细分几何边界不等于允许平滑改形；surface_remesh_mm 默认仍为0。薄壁弯曲和孔口应力分别做收敛验证。
5. 走线分析传入已核验的 G-code，核对模型/路径坐标和 `offset`；G-code 模式要求世界 Z 为层法线。解析器不支持的指令应先调查，不能静默忽略挤出圆弧。无路径时只能声称统一方向假设。
6. 显式记录材料参数来源。当前默认正交各向异性参数是演示值，不能当作实测 PETG。最近路径方向映射也不等于显式逐条打印丝或层间失效模型。

## 运行和交付

PowerShell 示例（替换工况与输出路径）：

```powershell
python D:/3d/toolpath_fea/run3d.py case.json --output output/job --timeout 300 --memory-mb 2048
```

相对输入路径按 case.json 所在目录解析。stdout 是单个 JSON，stderr 是进度 JSONL；使用清单 `artifacts` 定位本次工件，不靠扫描旧目录判断成功。默认有第二档网格检查；若初筛使用 `--no-convergence`，报告明确写“未验证收敛”。

检查 `status`、`exit_code`、`analysis.quality`、每条 `analysis.checks`、原始系统残差、反力/力矩平衡、网格质量、路径覆盖及输入哈希。退出码 0 仅说明流程完成。`--require-checks` 可让未通过的数值校核返回 8 并保留工件。

`solver: auto` 通常合适。极薄劣质四面体可能使 AMG 停滞，已有实现会在此情况下选择直接法。超时或内存超限后先定位原因，不自动无限放大预算；RSS 监控不是 OS 硬限额。

输出简洁工况说明、位移/应力、平衡与收敛状态，并提供图和报告。最大位移说明是全板最大还是加载点位移；峰值应力和全局 p95 不可混作局部收敛应力。HAPI 环境用可用 display_image/display_media 工具发送图和报告。

只有载荷幅值变化、其他条件相同的线弹性模型可按比例缩放；若以缩放生成结果，应标明推算而非重新求解。不能从此模型宣称断裂载荷、安全承重或长期蠕变性能。真实挂钩接触、装配、多体连接、失效与几何非线性超出当前求解器能力，需另建相应模型。
